DIECAST ARCHIVE v0.2 — iPHONE EDITION

1. Keep a JSON backup from v0.1 before updating.
2. v0.2 uses the same localStorage key (diecast-archive-v1) as v0.1 on the SAME origin.
3. Opening index.html directly on a laptop works, but offline PWA installation requires HTTPS hosting.
4. To deploy: create a public GitHub repository, upload the CONTENTS of this folder (not the enclosing folder), and enable GitHub Pages from main branch / (root). GitHub Pages publishes source files publicly; do not upload catalogue data or backup JSON.
5. On iPhone: open your HTTPS GitHub Pages URL in Safari, Share > Add to Home Screen > Add. Open the installed app while online once. Test airplane-mode reopening.
6. Import Apple Notes data on the iPhone, or use Export backup on laptop and Restore backup on iPhone. Local data does not sync between devices.
7. Export a JSON backup to Files after importing, and periodically thereafter. iOS can clear website data; uninstalling the Home Screen app may delete stored data.
8. GitHub Pages website is public, even though locally entered catalogue data is not uploaded to GitHub by this app.
9. If you later change the website URL or hosting domain, the browser considers it a new storage location; restore from JSON backup.
